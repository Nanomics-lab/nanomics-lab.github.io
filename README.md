# Nanomics website draft

Open index.html in a browser to preview. All content and styles are in that file; no build or installation is required.

## Publish with GitHub Pages
1. Create a public repository named OWNER.github.io, replacing OWNER with your GitHub account or organization name. The nanomics.github.io address requires ownership of the nanomics account or organization; availability has not been checked.
2. Upload index.html to the top level of the repository and commit it to main.
3. Go to Settings → Pages. Select Deploy from a branch, main, and /(root), then Save.
4. Wait for deployment. The published link appears in Settings → Pages.

A repository with another name uses https://OWNER.github.io/REPOSITORY/ instead. This site supports either form.
